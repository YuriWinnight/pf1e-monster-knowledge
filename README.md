# Pathfinder 1e Monster Knowledge

Модуль для Foundry VTT 11 и системы Pathfinder 1e (`pf1`). Он добавляет расчёт числа вопросов о монстре по броску навыка Знания и КО выбранной цели.

## Что делает

- Добавляет кнопку **«Вопросы о монстре»** к сообщениям чата, похожим на броски навыков Знания.
- Игрок выбирает цель стандартным инструментом Foundry **«Выбор цели»** и нажимает кнопку у броска.
- Игрок сразу получает окно выбора вопросов по цели; после отправки выбранных пунктов ГМ получает приватный запрос с кнопкой ответа.
- Формула: `СЛ = 10 + КО + модификатор редкости`; при успехе 1 вопрос, ещё +1 вопрос за каждые 5 сверх СЛ.
- Для ГМ добавляет кнопку на панели инструментов токенов. ГМ выделяет монстра, вводит итог броска и выбирает видимость сообщения: публично или только игроку и ГМ.
- Опционально включает интерфейс выбора информации: ПЗ, КБ, касание, врасплох, характеристики, снижение урона, иммунитеты, чувства, языки, скорость, спасброски, ЗБМ/МБМ, особенности, навыки и «другое».
- Для особенностей есть два режима: выбор из предметов/особенностей актёра по названию или перетаскивание предмета ГМ-ом; ссылки на особенности можно открывать для чтения.

## Установка вручную

1. Распакуйте папку `pf1e-monster-knowledge` в `{userData}/Data/modules/`.
2. Перезапустите Foundry VTT.
3. Включите модуль в мире Pathfinder 1e.

## Настройки

В настройках модуля можно включить или выключить:

- кнопку у бросков Знания;
- отдельную кнопку ГМ на панели токенов;
- интерфейс выбора конкретной информации;
- упрощённые вопросы, объединяющие часть близких пунктов в один вопрос;
- режим особенностей;
- редкость по умолчанию: распространённая, обычная или редкая;
- звук запроса для ГМ и его громкость.

## Примечания

Модуль старается читать данные PF1e через несколько возможных путей `actor.system`, потому что структура данных системы может отличаться между версиями. Если какая-то характеристика конкретного листа не подтянулась, ответ ГМ можно отредактировать перед отправкой.

## Версия 1.1.0

Изменения по интерфейсу и выводу:

- Кнопка у броска Знания теперь компактная: только значок мозга с подсказкой при наведении.
- Добавлены вопросы: «Уязвимость к урону» и отдельная «Невосприимчивость к энергии».
- Старая «Невосприимчивость к энергии» переименована в «Невосприимчивость к урону», потому что использовала блок иммунитетов к типам урона.
- Снижение урона выводится коротко, например `5/Режущее`, и учитывает поле особого снижения урона.
- Чувства собираются из отдельных полей: сумеречное зрение, ночное зрение, виброчувствительность, слепозрение, нюх, видение невидимого, истинное зрение, видение во тьме и пользовательская строка.
- Скорость и навыки теперь выбираются отдельными подпунктами; каждый выбранный подпункт стоит 1 вопрос.
- Навыки и особенности выводятся отдельными строками.
- Особенности в режиме выбора из предметов актёра показываются с иконками и выводятся в чат как отдельные карточки.
- После исчерпания доступных вопросов оставшиеся чекбоксы блокируются, а не закрывают окно с ошибкой.
- Добавлены встроенные русские названия для основных типов урона, энергетических типов, условий, языков и чувств. Если подключён перевод PF1e, модуль также пробует использовать строки локализации Foundry.

## Версия 1.5.0

- Заголовок ответа и название цели сделаны заметнее.
- Названия ответов вроде «Снижение урона:», «Чувства:», «Языки:», «Скорость:», «Особенности:» теперь выделяются жирным, а значение остаётся обычным текстом.
- Несколько выбранных навыков выводятся столбиком без большого пустого промежутка между строками.
- Кнопка у броска стала только иконкой мозга без визуальной плашки и размещается справа внутри блока результата броска.
- Скорости всегда доступны отдельным выбором: наземная скорость, лазание, плавание, рытьё и полёт. Каждый пункт стоит 1 вопрос.
- Основной блок выбора визуально разделён на группы без отдельных заголовков: КБ, защиты/иммунитеты/СУ, спасброски и ЗБМ/МБМ.
- Окна выбора и ответа стали компактнее и получили возможность изменения размера.
- Для особенностей добавлено числовое поле: сколько вопросов игрок хочет потратить на особенности. ГМ не сможет выбрать больше особенностей, чем было оплачено вопросами.
- Навыки `art` и `lor` переименованы в «Артистизм» и «Предания».
- После нажатия игроком кнопки сначала появляется приватный запрос ГМ с выбором редкости монстра и описанием изменения СЛ. Только после выбора редкости ГМ создаётся сообщение с количеством вопросов.
- Если у броска или выбранного токена найден актёр-спрашивающий, запрос идёт от имени этого актёра. Если актёр не найден, используется имя игрока.
